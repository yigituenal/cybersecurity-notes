# Public Key Cryptography

Asymmetric encryption uses two different keys.

- Public Key
- Private Key

---

## Public Key

Can be shared with everyone.

Used for encrypting data.

---

## Private Key

Must remain secret.

Used for decrypting data.

---

## Confidential Communication

Encrypt

↓

Public Key

↓

Decrypt

↓

Private Key

---

## Digital Signature

Sign

↓

Private Key

↓

Verify

↓

Public Key

Digital signatures provide:

- Authentication
- Integrity
- Non-repudiation
