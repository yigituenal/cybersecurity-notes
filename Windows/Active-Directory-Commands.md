# Active Directory Commands

## Current User

```powershell
whoami
```

Displays the currently logged-in user.

---

## Current Domain

```powershell
echo %USERDOMAIN%
```

Displays the current domain.

---

## Computer Name

```powershell
hostname
```

Displays the computer name.

---

## Network Configuration

```powershell
ipconfig
```

Displays IP configuration.

---

## Domain Information

```powershell
systeminfo
```

Displays system and domain information.

---

## DNS Lookup

```powershell
nslookup
```

Queries DNS records.

---

## Group Policy Update

```powershell
gpupdate /force
```

Forces Group Policy update.

---

## Group Policy Result

```powershell
gpresult /r
```

Displays applied Group Policies.
